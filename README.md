| โฟลเดอร์ / ไฟล์ | หน้าที่ |

## อัปเดตตารางคิวจากหลังบ้าน (วิธีหลัก)
ใช้หน้า back office ส่งออกไฟล์ `queue.js` ที่จัดรูปแบบพร้อมใช้ แล้วเอามาแทนไฟล์เดิม

1. เปิดหลังบ้าน แท็บ **เชื่อมหน้าบ้าน** หัวข้อ **ส่งออกให้หน้าบ้าน (เลือกเดือน)**
2. เลือก **เดือน** ที่ต้องการให้แสดงบนเว็บ (ค่าเริ่มต้นคือเดือนปัจจุบัน)
   - ติ๊ก **รวมคิวค้าง** ถ้าอยากให้คิวที่ยังไม่เสร็จจากเดือนก่อนติดมาด้วย
3. เลือกรูปแบบ **ไฟล์ queue.js (เว็บบน GitHub)** แล้วกด **ดาวน์โหลดไฟล์** (หรือ **คัดลอก**)
4. นำไฟล์ไปแทนที่ `website/content/queue.js` ในโปรเจกต์นี้
   - บน GitHub: เปิดไฟล์ → ปุ่มรูปดินสอ → วางเนื้อหาใหม่ทับทั้งหมด → Commit
   - ในเครื่อง: วางไฟล์ทับ แล้ว commit + push
5. รอ 1–2 นาที เว็บจะอัปเดตเอง

ไฟล์ที่ส่งออกมี **เฉพาะ** รหัสคิว ชื่องาน ชุด สถานะ วันที่คาดว่าเสร็จ หมายเหตุ ชำระเงิน
ไม่มีชื่อลูกค้า ราคา และต้นทุน ห้ามใส่ข้อมูลเหล่านี้ลงใน `queue.js` เพราะไฟล์นี้เป็นสาธารณะ

> ตัวเลือก "ทั้งหมด" ในหลังบ้านจะส่งออกทุกคิวทุกเดือน ซึ่งจะทำให้ตารางบนเว็บยาวมาก ปกติเลือกเป็นรายเดือน

## อัปเดตตารางคิวด้วยมือ
เปิด `content/queue.js` แก้แถวที่ต้องการ เช่น

```js
{"id":"MP251106-01","name":"Makima suit","type":"เซตแมลงแกะ","status":"done","date":"2026-11-19","note":"","payment":"full"}
```

- `status`: `wait` ยังไม่เริ่ม · `wip` กำลังทำ · `done` เสร็จแล้ว · `no` ยกเลิก
- `payment`: `full` เต็มจำนวน · `dep` มัดจำ · `none` ยังไม่ชำระ
- `date`: วันที่คาดว่าเสร็จ รูปแบบ `ปี-เดือน-วัน` (YYYY-MM-DD)
- เพิ่มคิวใหม่ = คัดลอกบรรทัดหนึ่งแล้วแก้ค่า (อย่าลืมเครื่องหมายจุลภาค `,` ท้ายบรรทัด ยกเว้นบรรทัดสุดท้าย)
- แก้เสร็จ commit + push แล้วเว็บจะอัปเดตภายใน 1–2 นาที

## เพิ่มผลงานในหน้า "ผลงานอื่นๆ"
1. ย่อรูปให้สูงประมาณ 440px (รูปแบบรวมหลายช่อง กว้างประมาณ 1000px) ไฟล์ละไม่เกิน ~250 KB
2. วางไว้ที่ `assets/images/works/` เช่น `work-20.jpg`
3. ใน `pages/works/index.html` คัดลอก `<figure class="work">…</figure>` มาหนึ่งอัน แล้วแก้ชื่อไฟล์ `width` `height` และ `alt`
   (รูปแบบรวมหลายช่องใช้ `class="work fit"`)

## ฟอนต์
ตัวอักษรทั้งหมดใช้ IBM Plex Sans (+ IBM Plex Sans Thai สำหรับภาษาไทย) กำหนดที่ตัวแปร `--font` ใน `styles/base.css`
ยกเว้นคำว่า "mipple" ข้างโลโก้ (Outfit) และชื่อเขียนมือในหน้าแรก (เป็นภาพ SVG ไม่ใช่ฟอนต์)
